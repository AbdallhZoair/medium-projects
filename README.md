medium-projects

This is where ideas go once they stop being a quick sketch and start needing an actual plan. Not big enough to deserve their own repo and a proper README, but too much thought went into them to get buried in a folder full of one-evening experiments.

Think of it as the step between "I had an idea" and "I had an idea and it fought back a little."

🗂️ How this is organized

Every project gets its own folder. Every folder has one job and does it properly this time. Naming follows snake_case — same rule as always, still free, still no excuse to skip it.

That's the whole system. Same as next door, just with more effort behind the door.

▶️Running any of these

bashcd <folder-name>
python3 <script>.py

No installs, no config files, no "works on my machine" surprises.

💡The philosophy here

What separates something landing here from small-project-s isn't the clock, it's the effort. A project earns a spot in this folder by actually making me think — some state to keep track of, some logic that isn't just an if-statement wearing a disguise. None of it took a week. Some of it took twenty minutes and more focus than I expected to need.

The really big stuff, the things with real scope and their own story to tell, get their own repo entirely. This folder is just where things stopped being easy.
